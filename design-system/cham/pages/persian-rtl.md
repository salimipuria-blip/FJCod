# Override: brand + Persian RTL (all pages)

Overrides MASTER.md (the generated starting point) for every page of CHAM Store OS.
Brand reference: `docs/brand/reference-cream-navy.png`.

- **Palette:** cream `#F3EBDD` background, navy `#12213F` primary/accent, sand `#B08D57` for small details. Replaces MASTER's stone + gold.
- **Fonts:** Markazi Text (Persian display), Readex Pro (Persian UI), Bodoni Moda (Latin wordmark). Replaces Cormorant/Montserrat, which lack Persian glyphs.
- **Direction:** `dir="rtl"`; charts run right→left; Persian digits, tabular figures.
- **Login:** a single password field on the cream "fabric" surface; no position picker.
- **Motif:** khatam girih only on navy surfaces, ≤16% opacity.
