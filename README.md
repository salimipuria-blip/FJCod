# چام | CHAM Store OS

سامانهٔ مدیریت فروشگاه چام — **لوکس · شیک · اصیل · اقتصادی**
اهرم موفقیت: **رشد، و تکرار رشد**

طراحی و توسعه: **FJCOD** (مالک سیستم) · بهره‌بردار: **چام**

---

## شروع سریع

```bash
npm install
npm run dev        # توسعه: http://localhost:5173
npm run check      # تایپ‌چک + تست واحد + بیلد
npm run build && npm run e2e   # تست مرورگر سرتاسری (۱۹ سناریو)
```

استقرار: پروژه آمادهٔ **Vercel** است (`vercel.json`). خروجی ایستا در `dist/`.

## ورود: پوزیشن + رمز

در صفحهٔ ورود ابتدا **پوزیشن** انتخاب می‌شود؛ اگر چند کاربر در آن پوزیشن باشند، کاربر انتخاب و سپس **رمز** وارد می‌شود.
رمزهای اولیه (در ورود اول **الزاماً** باید تغییر کنند):

| پوزیشن | کاربر(ها) | رمز اولیه |
|---|---|---|
| مالک سیستم | FJCOD | `fjcod1405` |
| مدیر فروشگاه | مدیر فروشگاه | `111111` |
| معاون فروشگاه | معاون فروشگاه | `222222` |
| صندوقدار | صندوقدار ۱، ۲ | `333333` |
| مشاور فروش | مشاور ۱، ۲، ۳ | `444444` |

## ماژول‌ها
داشبورد نقش‌محور · صندوق فروش (بارکد، تخفیف کنترل‌شده، امتیاز، پرداخت ترکیبی، رسید ۸۰mm) · صف سبد مشاور ← صندوق · فاکتورها و مرجوعی · شیفت و تطبیق صندوق · **موتور رشد** · باشگاه مشتریان · گزارش‌ها و خروجی اکسل · کالا و انبار · کاربران و ماتریس دسترسی · تنظیمات · سیستم، مجوز و پشتیبان‌گیری

## «همیشه آماده، بدون خطا»
- دادهٔ نمایشی کامل در اولین اجرا؛ دکمهٔ «شروع کار واقعی» برای پاک‌کردن آن
- اگر دادهٔ ذخیره‌شده خراب باشد، نسخهٔ خراب کنار گذاشته و سیستم سالم بالا می‌آید
- هش رمز بدون وابستگی به HTTPS (روی شبکهٔ محلی هم کار می‌کند)
- فونت‌ها داخل پروژه (بدون نیاز به اینترنت)، مرز خطا (Error Boundary)، همگام‌سازی بین تب‌ها
