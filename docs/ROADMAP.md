# نقشهٔ راه سامانهٔ چام (CHAM Store OS)

> **مالکیت دوگانه:** «FJCOD» مولد و ایده‌پرداز سیستم است و «چام» با پرداخت هزینه از آن استفاده می‌کند (بهره‌بردار).
> **هویت برند:** لوکس · شیک · اصیل · اقتصادی
> **اهرم موفقیت:** رشد، و تکرار رشد

---

## ۱. تحلیل نیاز و ابعادی که اضافه شد

درخواست اولیه شامل ورود با «پوزیشن + رمز» و پنج پوزیشن بود. برای اینکه سیستم واقعاً در فروشگاه «بدون خطا» کار کند، این ابعاد ضروری هم اضافه شد:

| بُعد | چرا لازم بود | وضعیت |
|---|---|---|
| انتخاب کاربر در هر پوزیشن | چند صندوقدار و چند مشاور هم‌زمان داریم؛ هر نفر رمز و آمار خودش را دارد | ✅ v1.0 |
| تغییر اجباری رمز اولیه + قفل پس از ۵ تلاش ناموفق + قفل خودکار در عدم فعالیت | امنیت صندوق در محیط شلوغ فروشگاه | ✅ v1.0 |
| ماتریس دسترسی و قانون «فقط سطح پایین‌تر را مدیریت کن» | مدیر نمی‌تواند مالک بسازد، معاون کاربر تعریف نمی‌کند | ✅ v1.0 |
| شیفت صندوق و تطبیق نقدینگی (کسری/مازاد) | کنترل پول نقد = اقتصادی بودن | ✅ v1.0 |
| سقف تخفیف برای هر پوزیشن | جلوگیری از نشت سود | ✅ v1.0 |
| صف «سبد پیشنهادی» مشاور ← صندوقدار + پورسانت | مشاور فروش واقعاً در چرخهٔ فروش نقش دارد و پاداش می‌گیرد | ✅ v1.0 |
| مرجوعی جزئی/کامل با بازگشت به انبار و کسر امتیاز | واقعیت روزمرهٔ پوشاک و اکسسوری | ✅ v1.0 |
| باشگاه مشتریان: امتیاز، سطح برنزی/نقره‌ای/طلایی/الماس | موتور «تکرار خرید» | ✅ v1.0 |
| موتور رشد: زنجیرهٔ هفته‌های رشد، هدف ماه، پیش‌بینی، نیاز روزانه، فهرست دعوت به بازگشت، اقدامات پیشنهادی | پیاده‌سازی مستقیم «رشد و تکرار رشد» | ✅ v1.0 |
| مجوز و اشتراک (FJCOD ← چام) با دورهٔ مهلت | مدل درآمدی FJCOD | ✅ v1.0 |
| گزارش ممیزی (Audit log) | شفافیت بین دو مالک | ✅ v1.0 |
| پشتیبان‌گیری/بازیابی، «شروع کار واقعی»، بازنشانی نمایشی | آماده‌به‌کار در هر لحظه | ✅ v1.0 |
| تقویم شمسی، هفته از شنبه، اعداد فارسی، پذیرش ورودی با ارقام فارسی/عربی | بومی و بدون خطای ورود داده | ✅ v1.0 |
| حالت تیره، واکنش‌گرا (موبایل/تبلت/دسکتاپ)، چاپ رسید ۸۰ میلی‌متری، اسکنر بارکد | سخت‌افزار و محیط واقعی فروشگاه | ✅ v1.0 |

> ⚠️ **چهار تصویر مرجعی که گفته بودید ارسال شده، به این گفتگو نرسید.** هویت بصری فعلی بر اساس چهار ویژگی برند و موتور طراحی UI/UX Pro Max ساخته شده است. با ارسال تصاویر، تطبیق بصری در فاز ۱ انجام می‌شود.

## ۲. فازهای اجرا

### فاز ۰ — نسخهٔ ۱٫۰ (تحویل‌شده) ✅
سامانهٔ کامل تحت وب، تک‌دستگاهی، داده روی همان دستگاه، قابل استقرار روی Vercel. ۲۵ تست واحد و ۱۹ سناریوی تست مرورگر سبز.

### فاز ۱ — راه‌اندازی آزمایشی در چام (هفتهٔ ۱ تا ۲)
- [ ] ارسال ۴ تصویر مرجع ← تطبیق نهایی رنگ/لوگو/عکاسی محصول
- [ ] «شروع کار واقعی» از صفحهٔ سیستم + تعریف کالاها (یا ورود گروهی از اکسل)
- [ ] تعریف کاربران واقعی، هدف ماهانه و درصد پورسانت مشاوران
- [ ] تست با اسکنر بارکد و پرینتر حرارتی ۸۰ میلی‌متری
- [ ] آموزش ۳۰ دقیقه‌ای برای هر پوزیشن + پشتیبان‌گیری روزانه
- **معیار موفقیت:** ۱۰۰٪ فاکتورها در سیستم، اختلاف صندوق کمتر از ۰٫۵٪

### فاز ۲ — ابر و چنددستگاهی (ماه ۱ تا ۲)
- [ ] انتقال داده به **Supabase** (Postgres + احراز هویت سمت سرور + RLS بر اساس پوزیشن)
- [ ] همگام‌سازی لحظه‌ای صف سبد مشاور بین تبلت مشاور و صندوق
- [ ] PWA آفلاین‌اول: صندوق بدون اینترنت هم کار کند و بعد همگام شود
- [ ] پشتیبان خودکار روزانه و تاریخچهٔ نسخه‌ها
- [ ] ورود گروهی کالا از اکسل، چاپ برچسب بارکد

### فاز ۳ — خودکارسازی رشد (ماه ۲ تا ۳)
- [ ] پیامک خودکار: تشکر پس از خرید، دعوت به بازگشت، تولد، رسیدن به سطح جدید
- [ ] کد معرف (Referral) و پاداش معرفی — گام پنجم چرخهٔ رشد
- [ ] نظرسنجی رضایت (NPS) پس از خرید
- [ ] پیشنهاد کالای مکمل در صندوق (Cross-sell) بر اساس سبدهای گذشته
- [ ] هدف‌گذاری خودکار ماه بعد = عملکرد ماه قبل + ۱۰٪

### فاز ۴ — یکپارچه‌سازی‌ها (ماه ۳ تا ۴)
- [ ] اتصال به **سامانهٔ مؤدیان** (صورت‌حساب الکترونیکی، الزام قانونی)
- [ ] اتصال کارتخوان (ارسال مبلغ به POS بانکی)
- [ ] خروجی حسابداری و گزارش مالیات
- [ ] کاتالوگ آنلاین / لینک خرید اینستاگرام از روی همان موجودی

### فاز ۵ — محصول SaaS برای FJCOD (ماه ۴ به بعد)
- [ ] چندمستأجری: هر فروشگاه یک فضای جدا
- [ ] کنسول FJCOD: مدیریت مشتریان، صورت‌حساب اشتراک، تمدید خودکار
- [ ] سفیدبرچسب (White-label): رنگ و لوگوی هر فروشگاه
- [ ] چام = اولین مشتری مرجع و نمونهٔ موفق (Case study)

## ۳. شاخص‌های کلیدی (KPI) «رشد و تکرار رشد»

| شاخص | محل نمایش | هدف پیشنهادی |
|---|---|---|
| زنجیرهٔ هفته‌های پیاپی رشد | داشبورد، موتور رشد | ≥ ۴ هفته |
| رشد ماه به ماه (تا همین روز) | داشبورد | ≥ ۵٪ |
| نرخ خرید تکراری (۹۰ روز) | داشبورد، موتور رشد | ≥ ۴۵٪ |
| میانگین سبد خرید | داشبورد، گزارش‌ها | رشد ماهانه |
| تحقق هدف ماه | داشبورد | ≥ ۱۰۰٪ |
| مشتریان دعوت‌شده به بازگشت | موتور رشد | ۱۰۰٪ فهرست هر هفته |
| اختلاف صندوق | شیفت و صندوق | < ۰٫۵٪ |
| تخفیف اعطایی / فروش | گزارش‌ها | < ۵٪ |
