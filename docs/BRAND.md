# هویت بصری چام

## چهار ستون برند → تصمیم طراحی

| ستون | ترجمه در رابط |
|---|---|
| **لوکس** | پس‌زمینهٔ سنگی تیره `#1C1917` + طلایی برنجی `#A16207` / `#E6BE62`؛ فضای سفید سخاوتمند؛ سایه‌های نرم |
| **شیک** | سبک مینیمال سوئیسی؛ تایپوگرافی Vazirmatn با وزن‌های سنگین برای عدد؛ نام لاتین با Cormorant و فاصلهٔ حروف باز |
| **اصیل** | نقش «خاتم» (ستارهٔ هشت‌پر گره‌چینی) در لوگو، صفحهٔ ورود و کارت زنجیرهٔ رشد؛ تقویم شمسی؛ نام‌گذاری فارسی |
| **اقتصادی** | سرعت (بدون کتابخانهٔ سنگین، ~۱۱۷KB فشرده)، کنترل تخفیف و صندوق، نمایش سود و حاشیه |

رنگ طلایی نمودار با اسکریپت اعتبارسنج پالت بررسی شد: کنتراست ≥ ۳:۱ روی هر دو زمینه. نمودارها تک‌سری‌اند (بدون وابستگی به تمایز رنگی).

## تایپوگرافی

- لاتین/نشان: **Cormorant** (۵۰۰، ۶۰۰)
